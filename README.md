# EVE Abyss Companion

A free companion app for tracking Abyssal Deadspace runs in EVE Online.

No memory reading. No game hooks. Just reads the log files EVE writes to disk — 100% EULA safe.

---

## Features

- 20-minute countdown timer with room splits
- Automatic NPC detection from EVE combat logs
- 126 NPCs with kill priority, threat rating, and ewar tags
- Colour-coded overlay chips — Neut, Scram, Web, Damp/Dis, Logi, Paint, Boss
- Transparent always-on-top overlay — no Alt+Tab needed during runs
- Loot tracking with Before/After delta and live ISK/hour calculation
- Run history and stats by tier and weather

---

## Requirements

- Windows 10 or 11 (64-bit)
- [.NET 8.0 Desktop Runtime (x64)](https://dotnet.microsoft.com/en-us/download/dotnet/8.0) — free from Microsoft

> **Important:** Download the **.NET Desktop Runtime 8.0** specifically — not the SDK and not the ASP.NET Core Runtime.

---

## Installation

1. Download the latest `EveAbyssCompanionv1.0.0beta.zip` from the [Releases](../../releases) page
2. Extract the zip into its own folder — keep all files together
3. Run `EveAbyssCompanion.exe`
4. The first-time setup wizard opens automatically

See the included `USER_GUIDE.html` for full documentation.
